# SkellTune Mini on GitHub

Repository: https://github.com/skellyruno/skelltune-mini

Source is maintained on `main`. GitHub Actions starts Realtime-only Windows VST3 and portable DSP builds on source pushes. Open **Actions → Build SkellyTune Realtime VST3** to inspect the run and download a successful `SkellyTune-Realtime-Windows-VST3` artifact.

Do not install an untested VST3 over the only working copy. Back up any FL Studio project before testing state restoration. See [FL_STUDIO_RECOVERY.md](FL_STUDIO_RECOVERY.md).
