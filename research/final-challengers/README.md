Methods: independent Praat pitch estimates; common voiced frame masks per experiment group. Spectral distance = mean absolute smoothed gain-normalized log magnitude difference on active frames in 200–6000Hz. Level p10 = tenth percentile 20ms active window wet/dry RMS change. One 8s singer only, delay alignment uses declared transport, not measured wet source age. Not proof of perceptual quality or CPU improvement.
